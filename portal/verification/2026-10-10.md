# v0.2.0 verification — 2026-10-10

Scope: reusable portal toolkit, not any tracked application, model, circuit or AI-provider integration.

Final title regression: catalog entries prefer the rendered page heading over repeated Overview navigation labels. A normal heading/permalink example is covered; final Python total is 29.

## Methods

- Fresh authorized checkout; `python scripts/portal.py setup` created a local environment and installed the pinned direct requirements. No global installation. Existing dependencies retain their licenses; transitive packages remain not fully locked.
- `python -m unittest discover -s tests -v`: existing toolkit tests plus reader catalog contracts (deterministic revision, dependency change, missing/unsafe references, invalid metadata, inline placement and read-only source preservation).
- `node tests/test_reader_core.cjs`: 12 pure logic checks for first use, added/modified/removed, re-review, unchanged question marks, unsupported/cross-project state, invalid marks/URLs/baselines, and acknowledgment not changing reading marks. No browser automation in this script.
- `python scripts/portal.py check` / `python scripts/portal.py build`: content/nav/state/token checks and strict MkDocs build.
- Codex In-app Browser on loopback QA previews: English first use/baseline, Architecture To review mark and reload, filter, 375 px layout without document-level horizontal overflow. Shared reader component also exercised in a separate Turkish portal: first use, read/reload, empty search, actual rebuild comparison, and isolated 404/unsupported-state/blocked-storage harnesses. Test labels use QA origins/fixture identities, not real user preferences. No review backups or real application documents are published in this repository.

## Limits

Results are recorded only after commands finish. Final aggregate is in RELEASE.md and verification/result-0.2.json. Browser observations are selected manual cases, not comprehensive cross-browser, accessibility, or user usability research. Desktop Windows is the tested host; 375 px is viewport emulation, not proof of execution on a physical phone. macOS/Linux and other AI onboarding remain untested. JSON export has no built-in restore/import. Catalog comparison covers public documentation and declared dependencies, not every code/theme/chat change. Source publication is a separate Git operation, not website hosting or a release tag.
