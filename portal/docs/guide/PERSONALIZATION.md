# Kişisel tercihler

Belgeler bu konuşmanın dili olan Türkçe hazırlandı. Ayrı bir kişisel tercih profili oluşturulmadı.

İstenirse iletişim tercihleri kullanıcı onayıyla yayımlanmayan, Git tarafından yok sayılan `.portal/user-preferences.local.md` dosyasında tutulabilir. Hassas özellikler çıkarılmaz. Tercihler bilimsel doğruluğu veya işlem yetkisini değiştirmez.

Sayfa okuma işaretleri bundan ayrıdır; [inceleme merkezinde](../review/index.md) yalnızca bu tarayıcıda saklanır.
