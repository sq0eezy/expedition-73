# Terimler

| Terim | Bu projede kullanımı |
|---|---|
| Değişken | İncelenecek ölçüm; örneğin NDVI veya sıcaklık anomalisi |
| Trend | Seçilmiş dönemde zamanla değişimin yönü ve miktarı |
| Anomali | Belirli bir referans değere/döneme göre fark |
| NDVI | Bitki örtüsü araştırmasında değerlendirilen bir indeks; henüz seçilmedi |
| Kalite bayrağı | Veri sağlayıcının ölçüm/geçerlilik koşullarını belirten alanı |
| GIBS | NASA görüntülerini harita servisleriyle sunan sistem |
| GRACE / GRACE-FO | Su/kütle değişimi incelemeleri için değerlendirilen görevler |
| GISTEMP | NASA GISS yüzey sıcaklık değişimi analizi |
| p-değeri | Seçilmiş test modeli altında yorumlanan istatistik; yöntemsiz bir doğruluk puanı değildir |
| ADR | Önemli kararın bağlamını, gerekçesini ve sonuçlarını saklayan kayıt |
| Kanıt | Gerçek yöntem/komut, tarih, sonuç ve sınırlamayla tutulan kayıt |
| Öneri | Ekipçe kabul edilmemiş veya uygulanmamış seçenek |

Veri ürünlerinin ayrıntıları için [NASA kaynakları](research/DATA_SOURCES.md), analiz soruları için [bilimsel notlar](research/SCIENCE_NOTES.md).
